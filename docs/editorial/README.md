# Native review handoff

Regenerate the prioritized inventory with `npm run content:review`. The deterministic JSON is derived from the currently indexed decks, current app region/register inference, and generated pronunciation manifest. Edit source content or a separate review record, then regenerate; changes made only to the generated inventory will be overwritten.

Each row contains the stable card/deck IDs, Spanish, English, example, tags, explicit/inferred register, inferred region, current review metadata, and audio location/provenance. The first 20 rows require native review; vulgar/flirty material follows. Pilot-mission content gets an additional editorial batch when its script is selected.

`unreviewed`, null reviewer/audio acceptance, and `not-established` region verification mean the repository has no recorded acceptance evidence here. They do not claim that no person has ever looked at the material. All current manifest recordings are generated by the ElevenLabs pipeline, not documented human performances.

The separate [review ledger and release workflow](RELEASE_WORKFLOW.md) binds actual attributed decisions to exact teaching versions. Regenerate the inventory after changing source or the ledger. The development library is not release-approved.

## What the editor supplies

For each accepted/corrected card, record stable ID, corrected text/translation/example, actual regional applicability (including shared usage), relationship/register guidance, reviewer attribution, review date, and unresolved questions. Review tú/vos/usted guidance in context. Do not assume deck membership proves exclusive regional usage.

Review conjugation fixtures as a separate batch: the source-generated future forms have been corrected automatically, but the entire 187-entry database has not been linguistically certified. The QA audit lists missing independent tú forms; the UI currently substitutes vos in those cases. Review before expanding grammar claims.

## Audio recording brief for a future human batch

AI can prepare final scripts and integrate files after the pilot phrases are selected. A human performer and editor are needed for the following:

- Confirm regional background and consent to the intended commercial use. Record the agreed license/release and attribution before distribution.
- Review the exact Spanish script before recording. Supply clear phrase recordings and short natural dialogue, with consistent stable IDs and speaker identifiers.
- Record clean, unclipped speech with natural rhythm. Keep room tone/noise low and provide unprocessed originals plus deliverable audio.
- Have an editor listen to every accepted clip against its transcript, checking omissions, stress, meaning, and naturalness. Record accepted/correct/re-record per clip.
- Keep generated audio as an explicitly identified fallback; do not relabel it as a human recording.

No speaker has been contacted, no recording commissioned, and no new paid synthesis run by this work package.
