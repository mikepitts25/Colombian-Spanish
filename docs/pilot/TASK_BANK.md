# Pilot task bank — editorial draft

**Not approved teaching or assessment content.** These are English-language task specifications and scoring rubrics for a qualified Colombian language editor to turn into parallel Spanish prompts, accepted variants and recordings. No human acceptance, equivalence, native audio or learner result is claimed. Keep answer material out of the participant-facing prompt.

## Form/version manifest

| Form | Intended use                          | Practical setting                                                                                 | Material needed before use                                                          |
| ---- | ------------------------------------- | ------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| A    | Counterbalanced pre or immediate post | Small café; ask for a drink, clarify takeaway, respond when unavailable                           | Accepted Spanish exchange, explicit variants and task rubric                        |
| B    | Alternate pre/post                    | Bakery; ask for a food item, clarify eating there, choose an offered alternative                  | Same number of communicative subgoals and comparable vocabulary/support             |
| C    | Immediate transfer                    | Different café; requested item unavailable, ask about a different offered item and complete order | Untrained surface details/branch, accepted alternate responses, novel-speaker audio |
| D    | Next-day check                        | Simple shop exchange with a changed item and availability response                                | New parallel prompts, accepted variants; no trained model phrase visible            |
| E    | One-week check                        | Same practical skill in a new everyday setting                                                    | New parallel prompts, comparable demands, actual time gap recorded                  |

Counterbalance A/B order; do not always give everyone the easier form first. No scripted form is assumed equivalent until a reviewer accepts its difficulty, vocabulary, speech pace, assistance and scoring. If the pilot exposes a material mismatch, report it and revise a new version rather than retroactively changing the old rubric.

## Communicative subgoals

1. Open the exchange appropriately for the setting and relationship. Evaluate whether the opening communicates appropriately, not use of one required slang word.
2. Request the intended item politely and intelligibly. Preserve equivalent reviewed forms; pronunciation judgment is human and distinct from automatic transcript matching.
3. Understand an availability/clarification response with Spanish text hidden. Score item/availability meaning separately; record each replay. Reveal transcript only after the unaided attempt, then score assistance separately.
4. Handle an unavailable item by choosing a relevant alternative or asking a useful clarification. This is the transfer branch; an exact repeat of the memorized request alone does not satisfy it.
5. Close the practical exchange or confirm the final order. A form-specific final outcome specifies the correct item and service option so raters can evaluate whether the task actually succeeded.

For each applicable subgoal capture observed independent outcome first, any later assisted recovery separately, and unresolved language judgments as `needs-review`. Do not silently treat a skipped/not-observed subgoal as incorrect. Form-specific prerequisites can make a subgoal not applicable; document that before scoring. Avoid adding purchase/payment tasks to the pilot; no actual transaction is needed to simulate an exchange.

## Language/editor acceptance sheet

For each form provide: stable form ID and content version; author; reviewer/date/decision; exact participant prompt; exact Spanish stimulus; accepted communicative variants and meaning boundaries; common partial/incorrect examples with rationale; any register/region limitations; subgoal applicability; hint ladder; audio asset/speaker ID and provenance/rights; recording transcript for facilitator use only; and a model response withheld from participants until after their unaided attempt.

Have the editor compare forms side by side for number of turns, memory load, lexical familiarity, grammar demand, alternative-branch difficulty and prompt clarity. Keep playback/transcript and response assistance comparable across forms. An editor should score example responses before the facilitator uses the rubric. If two raters disagree on actual consented responses, retain both original judgments and adjudication rationale; do not invent agreement.

## Optional extension prompts, after the core pilot

A transport directions task can assess understanding a landmark and asking a clarifying question. A voice-note task can ask for a short logistical reply and assess relevant follow-up. These are future task families, not equivalent substitutes for the café/bakery forms without review. Do not mix their scores into the same pre/post metric as if they assessed identical material. Speaking can remain optional with a typed alternative, reported as a different response modality.

## Facilitator notes

Read only the participant scenario and outcome. Keep the model answer, alternate form and scoring sheet off screen. Ask “What would you do next?” when observing navigation; record any hint as assistance. If a learner asks for a word, first record the unaided attempt, offer the accepted hint if they want it and continue without embarrassment or penalty. Stop for discomfort or technical failure, record the cause, and avoid filling in a hypothetical successful result.
