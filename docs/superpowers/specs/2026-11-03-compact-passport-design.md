# Compact adventure passport

Selected direction: a compact passport cover below the Adventures heading, opening a modal stamp collection. Reuse the cover on Progress. The cover displays the stamp count and an explicit Open passport cue. Use theme colors, an inset border, a spine and a Colombian tricolor motif to distinguish it from visit cards.

The collection retains saved stamps, preview and historical labels, support details and revisit actions. Show an empty stamp placeholder before the first completion. A Start/Resume action opens the first unlocked unfinished visit directly. Close returns to the underlying list without self-navigation. Preserve stored progress and content eligibility. English and Spanish copy; scalable text and accessible controls.

Approaches considered: an open passport panel exposes stamps immediately but takes more space; the selected compact cover keeps the visits prominent while giving the collection its own space. A native modal avoids adding another navigation route.
