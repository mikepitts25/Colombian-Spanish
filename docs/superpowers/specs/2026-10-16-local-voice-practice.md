# Local voice practice draft

Purpose: let a learner explicitly record a short local response, listen back and discard it, with a useful text alternative. This is practice/self-check, not assessed pronunciation, transcription, task success or learning mastery. It remains a development-only preview while language/hardware/privacy acceptance is open. No provider, account, network upload, persisted learning event, SRS grade or daily credit is introduced.

Use the installed Expo audio/file APIs, not a new service dependency. Start only from an explained Record action, then request microphone permission. Denial/read failure must leave text practice and Back available. Offer OS settings only when permission cannot be requested again. Visible recording status/elapsed time, an explicit Stop and a native plus JavaScript 30-second limit bound each take. A recorded clip can be replayed/stopped or explicitly deleted; require deletion before another take so nothing is silently overwritten. Empty/missing/oversized clips are unavailable, not incorrect answers. Limit accepted output to 2 MiB of owned app-cache audio.

Stop and lifecycle cancellation invalidate pending permission/prepare/playback requests. Blur/background never starts or resumes capture/playback; active capture stops and its partial take is discarded. Finished clips may remain while this screen is in memory, but closing attempts deletion and does not export/back up recordings. Deletion/cleanup failures must not be described as success; retain an explicit retry while mounted and document OS cache persistence limits after process termination. Never delete arbitrary supplied paths or existing assets. The adapter tracks only the recorder's owned cache URI.

Architecture: a pure controller with injected permission/record/play/delete ports owns state, cancellation and bounded take lifecycle; a small native adapter owns actual recorder/player/files/audio mode. A bilingual dev-gated screen subscribes to the controller and provides deterministic text self-check fallback using existing bundled source text. No newly invented Spanish is required for the prototype. Test fixtures simulate permission, IO and audio behavior; do not claim they are microphone evidence. Use SDK54 installed types/source if the archived documentation redirects to current SDK58.

Critical acceptance: no late capture after Stop/Back/background; one recording at a time; cleanup/retry preserve file identity; no external audio or raw recording in observations/backups; accurate recording/replay/unavailable UI. Simulators can verify route/layout/denial; real capture/intelligibility/headsets/OS interruptions need a named candidate/device and permission authorization. No microphone permission is granted automatically during QA.
