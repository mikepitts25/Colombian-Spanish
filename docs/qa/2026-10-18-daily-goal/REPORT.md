## Problems and resulting behavior

Native Text Size3→11 made the existing form unreadable ([before](live-max-es-before.png)). The save handler separately committed target and new-card limit, lacked failure handling or a synchronous submission guard, and allowed controls to change during a save. Loading could fail while default values stayed editable. The bilingual footer promised fluency in 1–6 months from card counts; the static “Mixed ›” affordance did not describe the due-first scheduler.

The existing settings now load together and save through **one durable journal intent**. Positive integer targets and 1–100 integer new-card limits are validated before writes; current daily counters and unrelated preferences are read inside that transaction. Interrupted application rolls forward before later reads. The screen blocks Save until load succeeds, shows load retry, retains the exact failed save values, locks conflicting edits during pending/failed intent, and retries without claiming success. Provider reload requires a fresh budget; refresh failure stays retryable even if the settings are already committed. A repeated absolute target/cap write preserves intervening review counts. Back inside this form is blocked during the unresolved write; external OS/navigation interruption coverage remains open.

Measured content remounts on fontScale while values, intent and pending state remain above it. Enlarged controls stack/wrap and the entire form, including Back and Save, scrolls. Presets expose selected state; steppers expose named disabled boundary states. Action targets are at least 48 points; symbolic glyphs retain readable size while text scales. The footer now explains practice versus fluency, the new-card cap is labeled daily, and order copy states due reviews first without a fake selector.

A native save also exposed **stale Settings summaries** (5/10 after the confirmed 20/15 write, visible behind [the alert](es-saved-alert.png)). Settings now refreshes both values on focus, ignores late reads from an earlier focus, and labels summaries unavailable when a read fails. The editor remains available to retry loading.
