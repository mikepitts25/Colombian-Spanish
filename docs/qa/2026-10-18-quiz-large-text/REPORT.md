- Maximum-text completion gives a narrow 220-point, two-column stats block. [CORRECTAS/FALLADAS break into character fragments](completion-stats-largest-before.png), although the full scroll viewport is much wider. This is a content-width constraint distinct from the live measurement defect.
- Region/answer Pressables lack explicit button and selected/disabled accessibility semantics. Two new interaction regressions failed on those missing roles before production edits ([red output](red.log)).

## Implemented correction and automated guards

`QuizScreen` subscribes to `useWindowDimensions().fontScale`. Each empty/start/question/completion scroll subtree renews native measurements on scale changes; question identity still keys each new question. The enclosing screen retains region, shuffled question/options, selected answer, feedback, score and submission/pending refs. A text-size change resets scroll position, not quiz state.

At fontScale ≥1.4, result statistics use the full content width, stack vertically and separate with a horizontal divider; default-size layout remains two columns. No score, answer-generation, saving, event, scheduling or translation logic changed. Region and answer controls now expose button roles and selected/disabled state.

The new tests retain an empty selected-region filter through a live dimension change and keep a selected answer disabled through an unresolved post-event save, then preserve feedback and finish exactly once after another dimension change. They assert real stored recognition events and the completion payload. The pending storage/session dependency is controlled; no native fault injection is claimed. Jest does not measure native text geometry: the native before/after screenshots are the layout regression evidence.

All **18 quiz tests** pass ([focused output](green.log)). Full **96 suites / 934 tests** pass ([output](full-suite.log)); TypeScript, zero-warning lint and changed-source formatting pass. Full-project formatting, 47-deck/1,392-card/audio validation and editorial-ledger validation pass; all 1,392 cards still await current human acceptance. Fresh whole-branch review found no actionable issues after inspecting source/tests, checklist/report scope, representative screenshots and independently passing all 18 quiz tests, the evidence verifier and diff checks.
