# Barrio Home cup

Original local vector drawing adapted from the owner-approved Barrio Home proposal cup. No person, real business, location, external media, recording or redistributed font. White strokes on transparent background are tinted through the existing theme role at runtime. Decorative, hidden from accessibility,40×40-point display; remove at large text/narrow content.

The source SVG is128×128. Render with the already available external `@resvg/resvg-js` renderer; no product dependency is added. PNG is an exported asset, not a native UI screenshot or cultural acceptance.
