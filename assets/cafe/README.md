# Café Home artwork

Generated with the built-in image generation tool for the owner-approved café Home concept (November 3, 2026). `evening.jpg` is the text-free production illustration; `morning.jpg` edits the same scene to daylight. The app adds afternoon warmth and animated steam/lamplight. Native components supply every label and control.

Prompt summary: sophisticated textured gouache Colombian neighborhood café, friendly adult barista, painted tiles, bougainvillea, mountains and church down the street; coffee cup on counter; identical day/night framing; no lettering, UI, or baked steam. JPEGs are quality-90 exports of the generated originals. No external stock assets or new font packages were added.

The owner-requested November 3 refinement adds the same traditional black-and-cream Colombian sombrero vueltiao to the host in both lighting variants. Built-in image editing preserved the scene and cup/lamp positions; the daylight edit used the edited evening hat as its alignment reference. The previous un-hatted assets remain in Git history.
